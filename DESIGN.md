# Design System: Khanh Nguyen Portfolio

## Overview

**Creative North Star: "Field Notes"**

The portfolio is a dark, editorial workspace that lets real project work carry the visual interest. It is built for someone quickly scanning Khanh's work: a clear introduction, direct navigation, a live XFC capture, and evidence-led project pages.

The default theme uses forest-ink surfaces, warm paper text, and a moss accent with a small ember note in the hero. A light theme is available from every header and remembers the visitor's choice. Both themes avoid dashboard framing, neon technical motifs, generic hero metrics, and overly polished "AI portfolio" language.

## Visual Rules

- Lead with real project screenshots and gameplay rather than decorative illustrations.
- Keep navigation readable and comfortably sized; use plain labels that name their destination.
- Use generous whitespace and editorial rows instead of stacks of equal cards.
- Use moss only for interactive elements, technical metadata, and the active navigation state.
- Keep copy direct, concrete, and personal without overselling.

## Typography

**Display:** DM Serif Display  
**Body:** DM Sans

The display face gives page titles an editorial character, while DM Sans keeps body copy and technical details crisp. Keep technical tags secondary to the actual project evidence.

## Motion

On desktop pointer devices, a subtle moss wash follows the cursor across the site. The XFC capture on the homepage also tilts slightly and receives a soft glint. Effects are disabled for touch devices and people who prefer reduced motion. Theme switching is immediate and persists locally.

## Responsive Behavior

Desktop opens with the introduction beside the XFC capture. At tablet and mobile widths, the page becomes a single column, keeps readable navigation, and preserves the direct actions before the media.

## Do Not Reintroduce

- Dark navy, neon backgrounds, technical-grid decoration, or glassy dashboard cards.
- Fake chat, assistant, or dashboard UI.
- Small, compressed navigation.
- Repeated rounded cards when a project row is clearer.
- Motion that exists only to decorate the page.
